# Intelligent Multi-Pattern Search & Document Analysis Engine

A polished React + Vite academic project website based on the final DSA presentation. It demonstrates Aho–Corasick multi-pattern matching, Trie/failure links, document analytics, architecture, methodology, testing and applications.

## Run

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```
